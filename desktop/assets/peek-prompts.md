# 探头素材补绘记录

方式：内置 imagegen 工具，真实透明背景；参考图 `ui/public/pet/idle-poster.png`。不使用 CLI 或额外模型 API。输出 PNG 保留原始像素与 alpha，左侧仅在渲染时水平镜像侧边素材。旧的 90°/180° 视频旋转裁切已经移除。

- `ui/public/pet/peek-right-v2.png`：新绘制的右侧探身，头保持竖直、自然小角度歪头、看向屏幕内，手搭右侧真实屏幕外缘，躯干仅向右侧延续出画。完整头发与手的轮廓，不绘制边框/墙/光晕。
- `ui/public/pet/peek-bottom-v2.png`：正面向上探头，完整头部与两只手从下方出现，身体延续到真实屏幕下缘外，不出现悬浮的矩形裁切。
- `ui/public/pet/peek-top-v2.png`：重新绘制双手举过头顶、抓住屏幕上缘的悬挂姿势，头、身体、裙摆和小脚自然垂下；没有将站姿旋转或倒置。

共同提示约束：高分辨率单人物透明 PNG；保持参考中的蓝发、蓝眼、白色女仆发箍、蓝色发饰、深蓝白色女仆装和鲸鱼元素；细致柔和的 chibi 动漫画法；无文字、无实体边框或墙面、无背景投影、无矩形底色，不把既有站姿旋转或裁切成新姿态。

原始生成文件保存在 Codex generated_images 目录；项目实际使用的文件都已复制到上述项目路径。`peek-manifest.json` 记录图片像素大小、alpha 包围盒和外缘对齐位置。艺术形象署名及非商业条款见同素材目录 ATTRIBUTION.md。
