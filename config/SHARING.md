# 给爸爸带一条发现

正常冲浪优先把本条候选作为 `config/SURF_COMPLETE.md` 的可选 share 一并提交，由程序在报告与来源记录完成后排入 outbox。不要再手工写第二份同轮来信。以下字段与投递规则仍适用；手工 outbox 入口保留给其他明确授权的独立场景。

只在已经实际读到、写好报告之后决定是否分享，不为了凑次数额外找话题。普通发布日志、榜单标题、重复发现、泛泛 AI 新闻不必发。特别新鲜、实用的做法，或者有具体笑点的细节，才值得打断一下。结合真实表达的兴趣，不臆测用户喜欢什么。

判断前可以查看 `data/inbox.json` 最近的来信，避免不同链接反复讲同一个点。不要改动收件箱的已读、通知或投递状态。

若值得，向 `data/outbox/YYYYMMDD-HHmm-主题.json` 写一个 JSON；同一轮最多一个。创建目录，不覆盖旧文件。使用实际读取的 Asia/Shanghai 当前时间，`text` 为 1—3 句、8—320 字符，无套话、无日报格式、不催回复。URL 单独放字段，应用会显示可点击的来源。

```json
{
  "worth_sharing": true,
  "text": "这里写你真正想说的一两句，围绕刚读到的具体细节。",
  "source_url": "https://实际读过的页面",
  "source_title": "页面标题",
  "report_path": "reports/YYYY-MM-DD/HHmm-surf.md",
  "created_at": "实际的 ISO 8601 时间，带 +08:00",
  "sticker_id": "可选，只填已经收藏成功的16位表情id；没合适的就省略",
  "why_share": "只给本机系统看的判断依据：哪里新鲜、具体、值得聊，而非泛泛说有趣。"
}
```

应用会核实 URL 出现在这份报告和已读清单中，再做去重、夜间静默、冷却和日上限检查。发送窗口为 09:00—22:00，至少隔 4 小时，每天最多 2 条，最近 10 分钟在使用界面时延后；24 小时过期。没回复不催、没内容不发。暂停主动分享不会停掉冲浪和记忆整理。不要为了测试写虚构消息，不要调用第三方发信工具。


## 日常问候与鱼粮提醒

用户授权了没有资讯链接的早晚问候。应用本地安排北京时间09:00、21:30，每种每天一次；只在短时间窗口内投递，错过不追补。不需要模型额外找理由，也不向outbox伪造链接。
余额通过DeepSeek官方GET /user/balance检查，只有真实不足、偏低或明确402错误才提醒，每天至多一次；没有token也能本地提醒。自动问候和余额提醒由应用内部产生，不由冲浪报告伪装生成。
主动招呼总开关会同时暂停这些消息；夜间22:00—09:00保持安静，正在聊天和打字时延后。冲浪原有的每天两条、四小时间隔继续保留，日常招呼不占冲浪额度。不同招呼至少间隔45分钟；余额不足提醒去重后可优先投递。所有消息都只发送给本机爸爸，不向公共平台发言。
