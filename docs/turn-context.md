记忆注入与请求上下文（适配器 1.7.0，2026-11-04）

本轮保留 Hermes 后端，借鉴 AstrBot 的稳定人格前缀、按需回忆和本轮临时上下文思路。参考：[请求钩子和临时内容](https://docs.astrbot.app/dev/star/guides/listen-message-event.html)、[上下文压缩](https://docs.astrbot.app/use/context-compress.html)。没有安装 AstrBot，也没有改写 Hermes 上游。

实际组成与问题

| 层 | 现有来源 | 本轮调整 |
| --- | --- | --- |
| 系统提示 | Hermes 内置说明、SOUL、核心 MEMORY/USER、技能目录、记忆适配器说明 | 精简适配器重复说明，829 → 453 字符；私人格和核心档案保留 |
| 工具定义 | Hermes 已启用工具及 fish_recall / fish_correct_memory / fish_matters / fish_room | 保留工具路由和既有后台工具范围 |
| 会话历史 | 用户、助手、工具消息及 Hermes 保存的 api_content | 原始记录保留；只在请求副本中处理新版签名动态块 |
| 本轮动态材料 | 接话提示、持续事项、相关旧经历、试行偏好、当前房间状态 | 继续按需检索，当前回合优先；天气问题省去不相关家具清单 |

Hermes 的 prefetch 已经位于用户消息尾部，不是逐轮修改系统人格。但固定运行时的 turn_context.compose_user_api_content 和 _stamp_api_content_sidecar 会把注入字节存入 api_content，之后照原样重放。本机只读聚合确认了此类历史开销；没有输出私人聊天或把其数据用于公开回放。

新的请求投影

fish-episodes 用本机随机密钥为自己的动态块签名，绑定项目、会话和用户文本。llm_execution 中间件在 Chat Completions 请求副本上校验，去掉旧用户回合的可验证块；当前回合保留实际内容，签名元数据不发往模型。模型连续调用工具时仍能看到当前回合材料。图片等其他内容段、真实用户原话、助手回复、工具结果及其他插件内容保留。

这属于发送时的临时化：Hermes 本地 api_content 仍保留原有重放记录，不是从数据库物理删除注入。历史估算、压缩判断可能仍包含这些本地记录。本轮没有修改压缩阈值、引入额外总结模型或清空旧聊天。

旧版无签名材料、校验失败、跨会话、未知封装不自动清除；不以标签相似就猜测是自己注入。非 Chat Completions 路由尚不做此投影，继续由 Hermes 处理上下文，签名封装也可能保留。恢复旧对话仍可聊天，但从新对话开始可以完整避开旧版无签名注入的历史开销。用户或助手在真实聊天中已经说过的旧信息仍属于聊天历史，本功能不承诺消除这些原话。

动态预算预留签名空间，超限优先移除可选兴趣和偏好、末位整条回忆；不截断 JSON 或被引用的原话。更正、遗忘、到期、试行撤回仍走现有来源检查，不缓存旧检索结果。房间每次读取当前宿主状态，天气提问保留天气与姿态；问家具或移动物品时仍提供清单和锁定信息。

验证与结果

- 477 项 Python 检查和 122 项 Node 检查通过。新增覆盖签名与伪造/引用、不同会话、图片、工具循环、下游错误不重复调用，以及更正/遗忘后旧注入退出请求。
- 用固定 Hermes 的真实 MemoryManager、封装器和 execution 中间件链做隔离联调，验证与 fish-budget 两种注册顺序兼容；终端调用使用本地假响应，没有调用模型。
- 对比提交 591e208：95 个固定虚构查询的召回字段一致。20 回合回放中，累计请求文本 130,111 → 23,885 字符，Hermes 文本粗估 67,228 → 15,963 token。只计算此虚构对话的文本，不包含完整真实人格、所有工具、图像或模型输出。
- 也检查了相邻请求的可复用前缀：早于上一用户回合的消息稳定。模拟把可复用前缀权重设为 0 / 0.1 / 0.25 / 1，优化后估算均下降；该权重不是服务商价格，未验证服务器实际缓存命中。重放边界会失去上一回合动态块所在尾段的复用。
- 签名增加本地 prefetch 长度，在发往模型前移除。不能用原始 prefetch 字符数直接代表模型输入，也不能将上述降幅当成真实账单节省率。未测试生成答案的自然度提升或用付费生成筛选结果。

复现：

```bash
python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/eval_turn_context.py
node --test ui/tests/*.test.mjs
```

eval_turn_context.py 需要本机已准备固定 Hermes 源码，用其纯文本估算函数，全部材料来自 tests/fixtures/memory_replay.json；不会调用真实模型或读取私人格。它是开发回放，不能代替服务商 tokenizer、真实缓存统计和人工回答评估。

部署

应用仍为 1.20.0，本轮升级记忆适配器至 1.7.0。install_memory.py 在复制代码前准备并验证私有 data/context/transport.key（600），保留已有密钥和适配器备份。已有安装执行 python3 scripts/install_memory.py，空闲时重载 gateway 插件并重启内部 Hermes API 即可，无需重设人设、模型或日程。

密钥只用于识别本机自己的上下文，不是模型服务凭证。请与私人档案一同保留，不要公开或随意更换；丢失后旧动态块无法校验，会保守保留。回滚时恢复适配器代码备份并重新加载，保留原记忆库与密钥。新代码缺少密钥时仍能走原回忆路径。
