大肥鱼小屋 · 首个可体验版本

2026-11-02，应用 1.15.0 / build 20。此版本实现实施计划阶段 0、1 的基础样片，后续阶段仍在计划中。

**现在可以体验**

从应用导航打开“她的小屋”。三维卧室包含床、床头柜、书桌与电脑、椅子、书架、鲸鱼地毯、抱枕、杯子、书、绿植及墙面装饰。家具通过项目代码生成，材质、灯光和尺寸统一，没有下载第三方模型或复用参考视频中的未知资产。

可以拖动转视角、滚轮缩放、复位相机、切换台灯；房间氛围提供按北京时间切换的白天、黄昏与夜晚，以及晴、雨、雪。天气是装饰性氛围，没有读取用户位置或接入真实天气。氛围选择在本机保留，尚未提供家具布置存档。

现有高清透明角色动画用于房间人物；角色站在固定位置，通过三维锚点投影定位，夜间调整亮度。人物属于独立前景图层，尚未实现三维人物、走路、坐椅子或任意遮挡。有限相机角度和物品位置控制当前融合效果，不能直接推广到自由移动角色。

人物活动标签读取现有 companion 服务返回的实际状态。思考和浏览使用对应动画；普通空闲或未读来信不循环挥手，用户点击人物时短暂打招呼。书桌与书架提供通向真实探索日志和记忆空间的入口，未把模板书目或阅读进度写作真实经历。

**生命周期与成本**

Three.js 按需加载，小屋渲染独立于聊天输入。隐藏文档、原生窗口最小化、隐藏或被完全遮挡时暂停房间时钟与角色显示；恢复后读取当前状态，不补播后台累计时间。切页时清理相机控制、动画时钟、观察器、几何体、材质、纹理和 WebGL 上下文。

雨雪最多使用 72 个粒子；显示像素比上限 2，动画时钟上限 30fps。晴天相机静止时不持续重绘三维场景，静态阴影不每帧重复计算；角色视频由现有播放组件处理。系统“减少动态效果”时保留静态画面。数字为实现上限，不代表已测得的设备帧率或耗电结论。

图形上下文丢失提供恢复提示，允许重新打开房间；场景与页面加载错误局限于小屋。打开、切换氛围、点物品、打招呼均不调用模型；本轮没有付费模型生成测试。

**已经验证与待验证**

- 生产构建和 Swift 类型检查通过，应用已重新构建并安装。
- 447 项 Python、72 项 Node 检查通过。新增测试覆盖北京时间边界、无效持久化选项、活动映射、时钟暂停/恢复/销毁，以及 27 组视口比例和相机角度组合下房间边界不被默认视角裁切。
- 在实际 macOS WKWebView 中检查了三维场景、高清透明动画、夜间灯光、雨天、物品介绍、相机旋转、窗口缩放与最小化恢复；恢复后房间仍正常显示。
- 尚未完成最小窗口的完整人工操作检查、中文输入法组合回归、1 小时以上后台与真实睡眠唤醒、强制图形上下文丢失恢复，以及成套 CPU/GPU/内存性能测量。几何投影测试不能代替这些检查。
- 前置记忆修复独立提交并确认实际适配器版本 1.6.14，原有配置、身份、任务、来信、记忆与 gateway 进程保全检查通过。

Three.js 场景独立代码约 580 KB、gzip 147 KB，仅进入小屋时加载；生产构建保留该分块大小提示，未通过提高阈值隐藏提示。
