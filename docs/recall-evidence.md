# 1.14.2：泛词不单独成为聊天里的旧经历

本轮改善自动聊天上下文的取舍，不修改原始记忆、索引内容或手动搜索结果，也不接入向量模型。应用界面、工具定义和提示词长度不变。

## 原因与改动

原有检索只要某个片段覆盖够多就可能通过。像“最后”“恢复”“密码”这样的词，单独就能满足一个短片段，导致厨房渗水的问题取到“最后装好齿轮”，游戏账号密码的问题取到“没有保存快递取件密码”。

[dsh-fish-memory 的实现](https://github.com/Yuuyuko-uu/dsh-fish-memory/blob/main/lib/index.js) 区分证据、通用词频和排序，也讨论小库里普通词碰巧稀有的问题。本轮参考证据门槛的思路，没有复制其代码、引入词典或更换原有分词。

在原有相关性与有效期检查之后，自动召回还要求命中词不全是小组通用叙述词、进度词或字段名。只有“最后”“换了”“一起”“密码”等重合时，不把来源带进模型上下文。其他内容词仍可作为线索；“晚上打字的声音怎么变小”还能按“打字”找到静音键盘，不要求整句话原样出现。

显式设置的完整别名继续有效，即使用户把一个事件标成“最后”。英文别名须按完整词匹配，来源到期、遗忘或更正后仍遵守原有规则，不能靠别名例外恢复旧资料。手动搜索保留宽泛关键词查找能力，过滤只用于 `recall` 及其调用的严格检索路径；界面不新增开关。

尝试过统一提高整句覆盖率，它会减少误取，也会误伤“晚上打字”等真实转述，因此未采用。弱词清单是有限的确定性规则，不是中文语义理解；“邻居的猫”与“邻居的狗”、打印设备与耳机支架等主体混淆仍可能发生。

## 隔离回放

```bash
python3 scripts/eval_recall_evidence.py --baseline 823516b
python3 scripts/eval_memory.py
python3 -m unittest discover -s scripts -p 'test_*.py'
node --test ui/tests/*.test.mjs
```

使用相同虚构数据分别构建两版临时库，不读取实际聊天、不调用模型或访问网络。比较真实 `recall` 返回的上下文编号，同时核对普通手动搜索的前五个结果。不是只对词表本身计数。

新增 `tests/fixtures/lexical_precision.json`，在筛选实现前固定六段经历、十个正例、八个无对应目标的负例和两个相关但缺少所问细节的控制。此前 40 个语义转述样例已经在开发中查看；所有结果均为开发者样例，不能称作外部盲测。缺少度数、号码等细节的控制不算作“必须没有相关记忆”的负例。

| --- | --- | --- | --- |
| 原有 91 问 | 78/79 | 78/79 | 0/12 → 0/12 |
| 先前转述开发集 | 5/20 | 5/20 | 5/16 → 4/16 |
| 新增边界样例 | 10/10 | 10/10 | 2/8 → 2/8 |

三组手动搜索结果均保持一致。自动上下文发生的变化包括：

- 小禾推荐的电影只带电影经历，不再附上仅同样出现“推荐”的另一本小说；反方向也如此。
- 问水槽渗水最后怎么处理时，不再取回齿轮或电脑维修。真正渗水的记录仍未被词法方案找到，不能把“少放错材料”算成“已经想起来”。
- 问白衣服染色不再只因“一起”带入旧齿轮记录；问报时圆盘也不再因“换了”“恢复”带入电源、面包、自行车、键盘。
- 游戏账号密码不再取回快递记录；共享单车扣费的正确来源保留，少带手机处理和磨脚经历。

剩余错误没有隐藏：先前的十六个负例仍有四个带入上下文，新八个负例还有两个；深层转述仍会漏召回。这些统计是检索取舍，不是最终回答正确率。原有 91 问的上下文由 27,653 到 27,253 字符，只能说明这组引用片段少了 400 字符，不是日常账单或总输入节省比例。

五个新增测试覆盖泛叙述误取、字段名缺少主体、短实词转述、明确别名与到期、更正及遗忘后的例外失效。Python 157 项和 Node 63 项全部通过；索引修复、日期、来源更正、持续事项及原有只读路径检查继续通过。

安装后用固定版本的真实 Hermes `MemoryManager` 离线核对自动预取、回忆工具、手动查找与机器人输入排除；仅使用临时虚构库。对照本机在线备份，已有来源行、历史与事项保留，私人身份和模型配置未改变；三个日常任务的定义保持，调度运行字段允许自然推进，原 gateway 进程未重启。

## 升级与后续

更新回忆适配，在空闲时重载 gateway 插件、重启内部 Hermes 接口；应用版本为 1.14.2。无需重新设置人设、模型或三个日常任务。记忆库使用 SQLite 在线备份，原来的经历仍可在面板查看和手动搜索。已经载入旧上下文的对话可能继续受之前材料影响，新对话可避开旧片段。

后续继续处理对象混淆与低覆盖转述，同时验证本地向量候选的缓存失效和实际生命周期开销。本轮没有把语义实验结果混入正式召回，也没有增加模型工具或每轮评审调用。
