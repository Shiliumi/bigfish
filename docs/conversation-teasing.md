# 短句逗趣与前文铺垫

2026-10-29，记忆适配器 1.6.3、应用 1.14.3。针对把调侃当知识问答、回逗后继续解释和总结的问题，调整现有接话路径；没有新增面板、梗库、情绪分数或回复润色模型。

## 改动

静态接话说明从 1310 缩到 905 字符，保留多轮谐音、反话、接受纠正、认真求助、真诚夸奖、引用和记忆边界。示例只说明节奏，不包含私人截图原句、指定梗答案或需要轮换的模板。短反应能够成立时就停下，不再要求每句都有机灵比喻。

原来普通 casual / neutral 回合通常没有动态提示，单改 SOUL 又不能保证已有会话的缓存人设更新。现在对少量短句中的外形逗趣、荒诞气质、怪外号和调侃措辞提供一个 **playful 提示**。它明确只是“可能在逗趣”，请模型结合当前上下文和读音判断，不给固定答案、不认定对方设套、不编网络出处。这里使用有限文字规则，不是通用意图识别或梗理解器，仍有漏判与误判。

以“那……”“连起来”“外号”等接续的短句，还会参考同一会话最近两条、30 分钟内仍有效且未更正的原始用户话语，识别是否可能延续铺垫。中间的认真任务、明确难受、纠正或兴趣请求会阻断这条接续判断。不会跨会话借梗，也不持久化所谓当前情绪或逗趣状态。不把旧话再次复制进提示：真实历史仍由 Hermes 提供。

明确任务、难受、反馈、出处或词义问题保留优先级。逗趣提示不夹带冲浪兴趣；普通无关闲聊继续不加空提示包。动态提示只增加被选中回合的少量输入，没有额外模型调用；静态字符减少不代表供应商 token 或账单节省率。

参考了 [SillyTavern 的 Author's Note 官方说明](https://docs.sillytavern.app/usage/core-concepts/authors-note/) 中“当前会话的临时说明与默认角色资料分开”的设计。沿用已有 memory prefetch 注入，不复制其代码、不改 Hermes 上游，也不改写已有会话的系统前缀或聊天历史。

## 验证与限制

`test_conversation.py` 覆盖短句提示选择、同会话铺垫、时间边界、认真任务优先、引用与代码排除，以及遗忘、更正、到期和未来记录不能作为铺垫。完整 Python 检查 262 项通过。安装后的实际适配器还与固定版本 Hermes `MemoryManager` 在临时虚构目录验证了接话与接续提示；没有向真实聊天插入测试消息，没有模型生成。

新增 `tests/fixtures/conversation_teasing.json`，三组两轮虚构材料，分别覆盖外形与谐音、习惯回逗后转为难受、认真任务后真诚夸奖。用户台词和人工评阅要点预先固定，评阅要点不传模型，后续历史由当次模型输出续接。

```bash
node scripts/probe_conversation_play.mjs --live d619e88 --interactive --fixture=conversation_teasing.json
```

这是使用真实模型 API 的付费开发命令。本轮第一条请求即被既有后台额度拒绝，**没有生成任何对比回复**，没有提高限额、绕过记账或重试。因此本轮证据仅证明提示选择、安装和保留边界，不能据此宣称自然度提高或已学会特定梗。此前模型回放的有限观察保留在 [日常接话记录](conversation-banter.md) 和 [接话修复记录](conversation-repair.md)。

## 已有安装

```bash
python3 scripts/update_conversation_guide.py
python3 scripts/install_memory.py
```

第一条只替换私人 SOUL 的 `FISH_CONVERSATION` 标记区并备份，其余身份和成长区保留。第二条备份并更新适配器代码，不重设模型或任务。空闲时重载 gateway 插件、重启内部接口。动态提示在加载新版适配器后的回合生效；新对话加载新版静态说明，旧对话的缓存前缀保持原样。不要运行 `setup_profile.py` 重建私人设定。
