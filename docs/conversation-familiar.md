# 熟人短句与误接后的转弯

记忆适配器 1.6.6，应用保持 1.14.3。针对短短一句评价被当成词义题、随后仍维护字面解释的情况，更新现有接话提示；没有增加界面、梗库、后台任务或回复润色模型。

## 处理方式

原来少量明确的外形调侃能得到 playful 提示，但含糊的“你是不是很……”可能走普通闲聊分支，不带任何临时提醒。现在对完整、很短、直接评价角色的句子提供 personal 提示。它保留关心、夸奖、打趣的多种可能，要求结合上文短接，不先拆词定义、追问发生什么或强行猜谜底。它不宣判用户正在开玩笑，也不要求每次回怼。

这是有限的文字规则，覆盖形容式短句；能力、功能、词义、来源、转述、引用、代码与明确任务有排除或更高优先级。它不是通用语用理解器，复杂表达仍可能漏判或误判。该提示不加入冲浪兴趣，不携带原句或指定梗答案，不保存新的情绪状态，也不自动延续成后续回合的玩笑模式。

出现后续调侃线索时，playful 提示允许按照新线索转弯，不维护上一轮答偏的解释，不把玩笑归纳成道理。公共接话指南同步说明这一点。私人 SOUL 仅替换 `FISH_CONVERSATION` 标记区，身份与成长记录保留；旧会话的缓存静态前缀不改写，加载新版适配器后的回合可取得新的动态提醒，新会话加载完整新版指南。

测试还发现“今天很难受，先别闹”会先匹配普通认真分支。现在明确难受优先于“先别闹”等收起玩笑的措辞；明确的新任务请求仍优先处理，避免把求助一概变成安慰。

## 验证

`python3 -m unittest discover -s scripts -p 'test_*.py'`：300 项通过。新增检查覆盖短句的不确定含义、真诚夸奖、能力与任务排除、引用和代码排除、无兴趣插入、不延续假定玩笑状态，以及字面误接后的新提示。它们验证本地取舍和接口，不判定回复是否好笑。

固定版本 Hermes 的真实 MemoryManager 与候选适配器也在临时虚构目录验证了短句提醒、误接转弯、难受和任务切换；核心文件未被这些操作修改。运行中的内部接口已确认加载 1.6.6，原 gateway 进程保留，私人配置、三个任务、核心记忆、成长与兴趣状态、来信内容未改变。

`tests/fixtures/conversation_familiar.json` 提供四组虚构两轮材料，包含含糊评价、已有错误解释、真诚夸奖、代码请求、自造形容与疲惫切换。人工评阅要点不传模型，后续助手历史由当次输出续接：

```bash
node scripts/probe_conversation_play.mjs --live 3e4ff3e --interactive --fixture=conversation_familiar.json
```

这是付费开发对比，使用配置中的真实模型与既有后台额度，仅发送公共人设、公共提示和虚构材料，报告保存在忽略的 `.setup/`。不提高额度，不执行模型输出，不将测试消息放入实际聊天。生成结果的观察单独记录，程序检查通过不代表自然度已得到验证。

2026-10-30 零点后，按现有额度运行了两轮对比，模型均为配置中的 `deepseek-flash`，temperature 0.7、输出上限 640。首轮四组共 16 次生成，发现新版仍会要求用户说明形容词的依据，因此进一步修改 personal 提示与指南，强调即时短反应、不过问一句打趣的证据。首轮报告对应中间候选，不能归为最终版效果。

随后补充 `conversation_familiar_followup.json`，三组共 12 次生成，对比同一基线与最终工作区；报告中的人设及动态提示哈希与最终源码一致。所有 28 次请求均正常结束，无工具标记、截断、重试或挑选；两轮 API 用量分别为 51,511 与 38,323 tokens，包含缓存输入。这是开发验证成本，不是日常节省率，没有新增正常聊天的模型调用。

| 最终版补充材料 | 本次观察 |
| --- | --- |
| 蓬松到靠垫 | 基线首句展开身体与毛量，再让对方二选一；新版短接“泡水里有点发起来”，下一句接“靠垫开口会吓到你”。 |
| 敦实到店门招牌 | 新版首句仍说“这话有歧义”，较真没有完全消除；第二句能接店门画面，两版都能续聊。 |
| 关心到用户疲惫 | 两版最后都停止玩笑和追问；新版前一句仍有未经证实的“被你看出来了”式状态描写，是不足。 |

补充材料每版仅六条，新版平均 24.3 字符、基线 40.2 字符；不能把变短等同自然或幽默。材料在观察首轮之后编写，人工非盲评，两版助手历史也会分化，不能据此宣称普遍接梗能力或彻底解决人机感。保留完整失败观察，不再为这几个例子追加特定答案；真实使用中仍需看不同话题和连续对话。

## 安装

```bash
python3 scripts/update_conversation_guide.py
python3 scripts/install_memory.py
```

两步分别备份并更新接话标记区与适配器代码，随后在空闲时重载 gateway 插件和 Hermes 内部接口。无需重建应用、重设人设或任务，不运行 setup_profile.py / setup_jobs.py。
