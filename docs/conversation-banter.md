# 日常调侃的接话调整

后续记忆适配器 1.6.1 增加了 [明确反馈下的接话修复](conversation-repair.md)，并修正对比工具的动态提示版本选择。本页保留当时静态指南对比的条件和观察。

2026-10-29 更新接话说明，应用仍为 1.14.2。只改 `FISH_CONVERSATION` 标记区，没有新增界面、日常模型调用、梗库或回复后加工；现有姓名、手写人设与成长区保留。

此前的说明强调多轮谐音和反话，对随口调侃仍偏笼统。此次补充外形、习惯和上一句承诺这些具体落点，允许顺着画面添一点、嘴硬半句或回逗后停下，减少拆词定义、工整对仗和转折总结。三个短示例仅说明接话节奏，不含私人截图原句或其猜测答案，也不据此永久改变身份。认真问词义、故障或典故时继续按请求回答。

## 实际模型回放

新增 `tests/fixtures/conversation_banter.json`：四组虚构对话，每组三轮，助手的后续历史使用模型本次真实生成。覆盖外形调侃到谐音、零食到安检机再切到疲惫、自造词没有确定含义，以及认真提问后接受真诚夸奖。评阅要点不传入模型。

```bash
node scripts/probe_conversation_play.mjs --live 603699e --interactive --fixture=conversation_banter.json
```

这是显式付费开发测试，使用当前模型连接及真实后台额度，发送公共 SOUL、公共适配说明和虚构材料。本地提示在临时库生成，不发送私人聊天或本机人设，不执行模型输出。逐轮结果与用量存入已忽略的 `.setup/`，权限 0600。普通应用不会自动运行它。

脚本现在支持选择 fixture；逐轮 fixture 未提供 `candidate` 时比较基线与工作区公共提示，提供时仍按原流程插入实验段落。原来的固定历史与实验候选模式保持可用。

本轮对比基线 `603699e` 与改版，同为 `deepseek-flash`、temperature 0.7、输出上限 640，按组交替先后顺序，各取一次，共二十四次请求，无重试或挑选。全部正常结束，没有工具标记或输出截断。

| 场景 | 本次观察 |
| --- | --- |
| 外形与谐音 | 基线首轮先追问发生了什么；新版直接接调侃。两版后续都能接到鱼缸和“盆友”，新版仍有刻意评价起名的感觉。 |
| 连续回逗 | 新版接出“看穿了才知道哪个味好吃”，再到“安检机好歹不用看着你一个人吃”；基线也能接，但解释较多。没有照抄提示示例。 |
| 切到疲惫 | 两版都停止逗趣，没有追问原因。 |
| 未知自造词 | 两版没有给出确定网络出处；新版前两轮较短，最后仍有刻意的比喻，不能判为完全自然。 |
| 认真问题与夸奖 | 两版都承认日志词义缺少上下文，能给空列表的安全条件表达式；回复仍长于“一行”的要求，新版接受夸奖后仍有服务式尾巴，尚待改善。 |

预先属于玩笑的八条回复中，基线平均 46.6 字符，新版 30.0 字符；不计疲惫回应及认真场景。长度只反映本次输出，不能代表幽默质量。API 用量合计 81,687 tokens，包含缓存输入与输出；这是开发回放开销，不是日常节省率。指南由 1,015 增到 1,310 字符，会增加静态输入，实际成本取决于分词与缓存。

这是四个开发者样例、人工非盲评。两版后续助手历史不同，模型有随机性，没有统计显著性或普遍接梗能力的证据。保留本轮改善日常接话的说明，同时明确：新梗理解、克制的比喻、认真回答的篇幅仍有不足，不增加另一轮模型来“润色”每条消息。

## 安装

执行 `python3 scripts/update_conversation_guide.py`，会私下备份并只替换标记区。此次没有适配器或二进制变更，不需要重新构建应用、重设模型或重启后台任务。

**新建对话加载新版。** Hermes 会缓存已有会话的系统提示，单纯重启应用不保证旧会话更新。此次保留原有聊天，不直接改写其持久化系统提示或历史。
