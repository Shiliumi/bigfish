# 未晋升的人格试行也要核对当前支持

2026-10-30，记忆适配器 1.6.7，原生应用保持 1.14.3。复用现有试行、来源指纹和待复核状态，没有新增面板、工具、状态文件、评分模型或后台任务。

## 实际复现

原来稳定倾向会检查晋升依据是否失效，未晋升试行却只据当前有效的正负反馈计算“能否晋升”。唯一支持对话被遗忘后，试行不再满足晋升条件，但仍显示 trying，表达试行的原措辞仍能进入普通聊天。这会让一个已经没有当前依据的尝试继续影响说话方式。

同样，未晋升试行虽然能算出反例尚未消化，却没有把它映射到待复核状态；默认取舍仍可能把原措辞作为正在尝试的偏好。这是本地状态与上下文选择的缺口，不证明已经造成某次实际模型回复，也不等同于自然度问题的全部原因。

## 当前行为

- 没有当前有效的正面支持时，未过期、未撤回的试行进入现有 reconsidering 状态。来源更正、遗忘、过期、未来生效、对应报告缺失，或唯一信号变成 uncertain，都不能继续充当正面支持。
- 未晋升试行处于这一状态且缺少支持时，聊天与冲浪上下文只提供编号、类型、状态和通用暂停说明，不再通过“提醒别采用”重新复制其旧措辞。当前认真任务、表达试行临时停用等原有规则保留。
- 还有其他有效正面支持时，不一概停止整项尝试；新的 not_for_me / changed_mind 等反例尚未消化时，则先待复核。新正面跟进与既有三天冷却条件仍需要满足，等时间本身不能消除反例。
- 真实新跟进经原 feedback 命令核对后可以恢复 trying；不自动恢复被遗忘的来源，不修改试行 revision、事件或 SOUL 来模拟恢复。晋升的三天、独立经历、跨日期及试行后跟进要求保持原样。
- 现有卡片把 reconsidering 文案调整为“先重新核对一下”，涵盖来源变化与反例，不再一律声称出现了新反例。没有新增按钮或设置。

`has_current_support` 是读取时计算的接口字段，不写回试行库。暂停不是自动删除：面板和变化历史仍保留原试行，便于查看与主动放下。已写入 SOUL 的稳定倾向继续走原来的来源复核、动态提醒和 retire 流程；本轮没有自动改写静态人设或清理已载入旧会话的内容，不能称为完整级联遗忘。先前加载的历史回复也不会被重写。

## 查阅

[关于过时记忆的论坛讨论](https://www.reddit.com/r/aiagents/comments/1wotyiq/how_are_you_handling_stale_context_in_agent_memory/) 区分历史记录仍可保留与它仍有资格作为当前依据。这是使用者经验和需求线索，不是效果测量。

查阅了 [Memory-Collapse-Eval 的 verbatim 示例](https://github.com/DylanZSZ/Memory-Collapse-Eval/blob/main/bench/memory/verbatim.py)（blob `3fe8e54df0a05e03679b46a24b128678f0588562`）及 [接口中的 verified_gold_from](https://github.com/DylanZSZ/Memory-Collapse-Eval/blob/main/bench/contracts.py)（blob `d65144115a71a7cb449170c78aa826ae40b0632c`）：示例记录给定标准答案或环境确认的结果，失败时不凭预测补出一个正确答案，并把写入与读取分开。这提醒本轮验证应检查完整来源生命周期，而不是只检查条目存在。它是评测示例，不是人格失效处理器；没有复制代码、安装该框架、下载数据集或把它的论文数字套到本项目。

研究作者在 [项目说明](https://dylanzsz.github.io/faulty-memory/) 中讨论了持续改写经验可能带来的退化，也明确保留了研究局限。这里不据此声称人格培养必然有害；继续采用小幅试行与来源核对，而非增加一个模型反复重写人设。

隔离对比基线 `40562ca` 与新版，五种情况（遗忘、更正、过期、未来版本、唯一信号 uncertain）分别使用表达和兴趣试行，共十组虚构生命周期。基线十组都在上下文提供原措辞；新版十组都改为待复核且不提供原措辞。这个数字只验证本地上下文的选取，不是模型自然度、误记率或 token 节省率。

固定 Hermes 的真实 MemoryManager 分别加载暂存候选与已安装 1.6.7，在临时虚构目录验证支持有效时进入提示、来源失效后只留暂停说明、认真任务优先；初始化后的核心文件与试行文件保持不变，没有执行模型请求、写入实际聊天或更改真实成长记录。本机内部接口确认版本 1.6.7，现有记忆空间与聊天正常打开，已核对私人配置、身份、三个任务、成长、来信、游标及记忆/额度数据保留，原 gateway 进程未重启。

来源指纹一致不等于解释正确；有效对话仍可能被模型误读成某种喜好。本轮也没有自动从“别这么说”推断永久撤回某个试行，近期反馈和长期记忆仍走现有路径。暂停提醒会占用少量输入，没有新增日常推理调用，不宣称成本下降。

已有安装执行 `python3 scripts/install_memory.py`，先备份后更新适配器；空闲时重载 gateway 插件与内部接口，界面重新构建后在下一次打开加载。无需 setup_profile.py / setup_jobs.py，不重置人格或日程。
