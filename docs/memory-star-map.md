记忆星图（1.18.0，2026-11-03）

入口在「记忆空间 → 记忆星图」；小屋里点书架也可以打开。按用户本轮调整，先交付星图；房间走动、看电脑、睡觉、自主搬动与愿望仍在原计划里待做。

可体验的部分

- Three.js 三维星空，支持拖动旋转、按钮与 ⌘/Ctrl+滚轮缩放、视角复位和可选慢速旋转。默认静止；发光由点着色器完成，没有后期 Bloom 的持续渲染负担。
- 按共同经历 / 情境印象、固定状态、当前有效 / 包含过时及未生效记录筛选。搜索只查当前记法与手动别名，支持普通字面子串和 Unicode 规范化，不把旧原文拿回来当作新事实。
- 北京时间的起止日期、按日按钮与截止日期滑杆。日期指原记录时间，内容和有效状态始终采用当前版本；不是历史事实回滚或模型记忆重放。
- 点击星星或下方可用键盘的记录列表，查看当前摘要、版本、有效期和每条关联的具体依据。展开同一个来源编辑器，可以核对原始片段、查看明确标为历史的旧版本，以及更正、固定、标记过时或遗忘。
- 来源编辑器由原记录列表和星图共用；补上独立遮罩、焦点约束、Escape 关闭、内容滚动与固定关闭按钮，不依赖控制室的样式。

真实数据与连线规则

星图读取现有 `data/memory/episodes.sqlite3`，不建立第二份事实库，不改写人设、核心记忆或模型召回规则。没有额外模型请求、embedding 请求或外网服务。图形位置由稳定 ID 在本机生成，筛选顺序改变不会随机重排同一节点的位置。

只画两种可解释的连线：同一原对话在当前筛选中的相邻记录，以及相同的手动别名。两种依据可以共存，侧栏明确显示；不使用无依据的语义推断、不声称连线是因果。点的距离、布局和大小都不是记忆强度、人格成熟度或情绪测量。固定记录用粉色区分，过时 / 未生效记录在历史筛选里暗显；固定不会绕过有效期。

接口 `GET /api/memory-graph` 沿用桌面鉴权、跨站限制和 no-store。单次 SQLite 读事务取得计数、日期边界与最多 500 条节点，不向界面传递整份原文、修订历史、原始 session ID 或本地路径。图中的对话组是不可逆摘要，只用来排布。来源片段仍通过已有的按 ID 详情接口按需读取。

节点上限 500、连线上限 1000；超出时明确提示，并通过日期或搜索定位较早记录。连线属于当前展示子集，不冒充完整知识图谱。当前只覆盖共同经历库；核心 USER/MEMORY/SOUL 与冲浪报告不被自动切成星星，纪念物和兴趣来源接入仍另列后续工作。

更正、遗忘和恢复

面板收到 `fish.memory.changed` 后先收起旧图与旧来源，再读取最新状态。页面可见时每十秒核对一次，也会在窗口恢复时核对；外部更正、过时、到期或遗忘后移除不再有效的节点和旧别名关联。选中的版本或状态改变时关闭旧详情并提示，避免继续编辑过期内容。故障时清除旧投影，明确显示重试入口。

星图只在打开后按需加载。静止时没有持续动画帧循环；慢速旋转、操作与阻尼期间才继续渲染。隐藏窗口暂停图形和轮询，切走页面释放 renderer、几何体、控件、监听器与图形上下文。遵守系统减少动态效果设置；图形丢失时仍可用记录列表，支持自动恢复和手动重建。
