# 短句接续与换题边界

记忆适配器 1.6.12，应用保持 1.14.3。继续改善熟人聊天中“上一句在逗她，下一句却开始解释”的取舍，不增加界面、梗词典或回复润色调用，不更换已选模型。

## 修改

此前“你说呢”“你猜”“再品品”等省略短句不能延续临时接话提示；判断又可能越过一条无关的普通消息，找到更早的玩笑。现在在同一会话、最近 30 分钟内，按顺序核对最多两条相邻记录。明确的打趣铺垫可以承接这类短句，再按原来的短反应提示接话；换题、真诚评价、认真任务、难受和停止要求都能结束这段承接。

更正、遗忘、失效的最近记录仅作为边界，不返回其原文，也不跳过它接回旧玩笑。只有含糊的“你是不是很……”或关心、夸奖时，不据此认定正在开玩笑。没有保存持续的玩笑状态，也不把临时外号存成事实。原静态指南与所有回复示例保持原样；接话和人格试行继续共用一次判断。

这仍是有限的文字线索，不能替代模型对语气、反话和谐音的理解。跨出这两条历史、表达不在已覆盖形式内，仍可能漏掉；命中提示也不保证回得有趣。

## 验证

399 项 Python 检查通过，包含新增的短句接续、相邻轮次、换题与真诚表达、失效记录边界、含糊评价和 provider 试行取舍。固定 Hermes 的实际 MemoryManager 在临时虚构目录验证异步 sync、prefetch、任务切换和试行恢复，安装前后均通过，没有发送真实聊天。

`tests/fixtures/conversation_callbacks.json` 是四组虚构材料，不含私人截图原文。运行：

```bash
node scripts/probe_conversation_play.mjs --live a0cb620 --interactive --fixture=conversation_callbacks.json
```

本轮只运行一次，基线为 a0cb620，使用配置中的 `deepseek-flash`，temperature 0.7、输出上限 640。共 10 次实际生成，均正常 stop，无工具标记；API 用量合计 32,366 tokens，包含缓存输入，使用原有后台额度。报告保留在忽略的 `.setup/`，最终源码哈希已核对。

人工非盲观察：导航玩笑后，新版能承接“你猜、再品品”，没有基线后一句那么长的再次追问；两版认真单词请求均正确。换题后的新版仍回了“行，我保温”，不能确认完全摆脱了旧比喻；关心场景仍多添“鱼不关机”。基线也能接住玩笑，部分对照回复还虚构了水温感受。这些问题保留，不用变短代替自然度评价，不据十条输出宣称通用接梗能力提升。

## 安装

沿用 `scripts/install_memory.py` 备份并更新适配器；空闲时通过控制接口重载 gateway，并重启项目内部 API，保留原生窗口。私人 SOUL、模型配置、三个任务、成长记录、来信及已有记忆内容保持原样。新动态判断随适配器加载后的回合生效，无需重建应用或重置聊天。
