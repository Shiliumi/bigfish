# 1.10 记忆检索回放

运行：`python3 scripts/eval_memory.py`。可用 `--output /path/to/result.json` 保存结果；默认在临时目录建库并在结束后清理，不读取实际聊天、调用模型或访问网络。

样本在 `tests/fixtures/memory_replay.json`：33 段手写虚构经历、91 个常规查询（79 个应找回、12 个应留空），另列 3 个深层转述压力样例。涵盖昵称、常见同义词、数字、简称、手动别名、日期、修改、到期、遗忘、未来记录、长片段与弱相关干扰；额外单元测试覆盖数字房间号、全角英文、旧索引重建、异步生命周期等。

固定查询是在实现前写下的开发回放，包含 34 个预留验证问法；开发中检查过结果，不能把它当成独立盲测或真实用户成功率。别名场景的新版本具有人工显式标签，旧版不支持这项输入，两者并非完全相同信息量。未用私人聊天补题。

对照旧版提交 `f6f9bc5` 的 Journal 实现，使用相同的虚构样本和回放程序：

| 指标 | 1.9 | 1.10 |
| --- | --- | --- |
| 应找回的目标进入前五条 | 77/79 | 78/79 |
| 第一条就是目标 | 74/79 | 78/79 |
| 目标实际进入有限召回上下文 | 77/79 | 78/79 |
| 应留空的查询确实留空 | 8/12 | 12/12 |
| 长对话关键原词未进入节选 | 1 | 0 |
| 更正后旧值混入上下文 | 0 | 0 |

这验证的是检索和上下文构造，不验证回答措辞、事实理解或长期人格。不能把“目标在前五条”称作回答正确率。

改进包括：窄范围、可审查的常见词与拼写归一；手动别名；显式日期检索；主体覆盖筛选；相关性优先于固定和新鲜度；在双方原话中选取相关窗口；可重建的派生索引版本。默认最多四段、总计不超过 4,200 字符，不额外调用 embedding 或重排模型。

不声称解决所有语义转述。常规回放里“换轮胎后刹车的声音”没有找回描述“外胎、刹车蹭轮圈”的目标。另列的三个深层转述也未命中；旧版的一个电影命中只靠“电影”二字，同时存在弱关联误召回。新版本优先保守留空，不为刷命中率扩大猜测。后续若实际使用积累足够此类漏召回，再在隔离样本中对照本地向量检索，评估延迟、误召回、资源与收益后决定是否接入。

日期检索指原聊天发生日期，以北京时间计算。自动召回只有明确询问某天“聊过/说过/提过”时才按聊天日期限定，避免把“昨天买的键盘”误当成“昨天聊过键盘”。更正版本参与当前召回，历史原话仅用于来源核对；到期和删除规则在别名、索引重建之后仍适用。
