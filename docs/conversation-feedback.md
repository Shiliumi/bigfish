# 近期反馈在后续几轮继续生效

2026-10-29，记忆适配器 1.6.5，应用保持 1.14.3。本轮沿用聊天记录和现有动态提示，不增加面板、工具、后台任务、模型调用或新的状态文件，不自动改写私人 SOUL / USER 或成长档案。

## 问题与做法

此前“别老喊爸爸”“别每次解释”会影响当前回合，但下一轮普通闲聊可能没有任何动态提示，表达试行又重新进入上下文。原聊天历史仍会送给模型，不能据此断言模型忘了反馈；可确认的问题是本地提示和试行选择没有延续这项优先级。

现在从**同一会话最近四条有效的已保存记录、最长 30 分钟**内，提取少量明确的说话要求。只处理称呼频率、日常篇幅、习惯性问句，以及随意/正式语气这四个维度。后来的明确要求可以撤回或替代前面的要求；“可以叫爸爸”表示解除克制，不会强制每句都加称呼。当前的真实任务仍优先，要求完整解释时不因先前闲聊要简短而省略必要内容。

程序只把已选中的固定短提示带入本轮，不重新复制反馈原文、不执行旧消息中的任意指令，也不建立情绪分数。正在生效的反馈会暂缓**表达**试行，相关兴趣仍可选择；试行已撤回或需要复核的提示保留，避免失效倾向又被当作稳定人设。成长文件本身不变化。

一次性的“这道题详细讲”“这次回复短一点”不成为会话偏好；引用、代码、转述、条件句等先沿用文本排除规则。“这段代码不用解释了”也进入停止展开的反馈分支，明确的新任务请求仍可切回认真处理。规则有限，不是通用意图理解；复杂否定、混合指令、隐晦反馈可能漏判或误判。

这一机制只提供近期接话提醒，不代替长期记忆工具。超出记录/时间范围、跨会话、来源已遗忘、更正或到期时不延续；更正后的原始话语不重新提取。后台异步保存尚未完成的上一条反馈也可能暂时不在候选中，原聊天历史仍是模型的上下文，不承诺每一轮都会有本地提醒。

共同读取近期记录的函数还排除了未来的记录时间和未来的有效起点。此前重复话风统计没有记录时间上界，现在它和铺垫、反馈使用相同的有效时间判断。

## 参考与取舍

[近期关于重复回复结构的论坛讨论](https://www.reddit.com/r/SillyTavernAI/comments/1x9cgk7/looking_for_tips_on_breaking_response_structure/) 区分“词句不同”与“仍在重复同一种段落和问句节奏”，也提到额外编辑调用的代价。这是用户经验，不作为本项目效果证明。

[SillyTavern 官方提示说明](https://docs.sillytavern.app/usage/prompts/) 讨论了历史回复对后续话风的影响，以及当前提示的位置。[其 Author's Note 源码](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/authors-note.js)（所读 blob `0ef3d03d783d3452f1a2d288fac10ebf9178cbad`）把当前聊天的说明、插入频率和默认设置区分开。本轮借鉴会话范围与短期提醒的思路，不复制代码；继续通过现有 memory prefetch 注入，不改写历史回复、已有系统提示前缀或上游 Hermes。最初尝试的 extensions/notes 路径为 404，后按实际目录定位到上述文件，没有把失败请求当作源码审阅。

## 验证和成本边界

```bash
python3 -m unittest discover -s scripts -p 'test_*.py'
```

286 项检查通过，覆盖要求延续、分项撤回、后来要求优先、撤回语句的否定、一次性任务、引述排除、四条与半小时边界、跨会话、未来/过期/已更正来源、仅采用用户话语、停止展开、真实任务优先、表达试行暂缓及兴趣/撤回信息保留。

本轮使用既有 `conversation_probe_context.py`，在临时虚构库对照 `4049db1` 和工作区的本地提示选择。三组首轮对应提示由 0 / 182 / 0 字符变为 194 / 246 / 172 字符。它验证的是新增提醒确实出现；有反馈时会增加少量输入，不是 token 节省率。没有反馈的普通闲聊仍不产生空提示包，不增加另一轮模型来评分或润色。

实际安装的 1.6.5 还与固定 Hermes 的真实 MemoryManager，在临时虚构目录检查了：前一回合的反馈进入下一回合、表达试行暂缓、撤回后恢复候选、停止展开和新任务优先。初始化后的核心文件保持不变，未写入真实聊天或发送模型请求。

`tests/fixtures/conversation_feedback.json` 是三组三轮的虚构生成回放材料，包含普通接话、玩笑、认真任务、撤回与结束。后续可显式运行：

```bash
node scripts/probe_conversation_play.mjs --live 4049db1 --interactive --fixture=conversation_feedback.json
```

这是付费开发命令，沿用真实后台额度、版本化动态提示与私有报告。**本轮没有运行该付费生成回放**，也没有提高已接近上限的后台额度；程序测试不能证明模型会更自然或必然听从反馈。新材料属于开发验证，不是独立盲测。

## 已有安装

```bash
python3 scripts/install_memory.py
```

先在线备份记忆库与私人配置；安装器另存旧适配器代码。应用空闲、无草稿时重载 gateway 插件和 Hermes 内部接口，后续回合使用新版。无需重新构建应用、重设人设、模型或任务，不运行 setup_profile.py 或 setup_jobs.py。加载后的会话沿用原历史和缓存的静态前缀，这次只改变新的动态取舍。
