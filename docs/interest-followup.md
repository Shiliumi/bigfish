# “上次那个”接回当前会话的话题

记忆适配器 1.6.10，应用保持 1.14.3。修正追问被新兴趣顶替的问题，没有增加界面、模型调用、后台任务或第二份记忆库。

## 实际问题

现有兴趣选择会优先挑尚未分享、较新的一件。这适合“最近看了什么”，却也应用到了“上次那个后来怎样了”：隔离虚构材料中，之前聊过纸齿轮，另有尚未讲的玻璃花盆，旧版错误选了后者。这是本地选择错误的复现，不是实际用户说过这两件事。

## 调整

继续沿用原有、带真实阅读依据的兴趣候选，只对少量明确追问措辞单独处理：

- 点出对象时保留名称，包括引号内的标题；明确匹配唯一候选才提供，多个候选有匹配时不按词数多少强猜，未匹配的明确对象也不借用上次的话题。
- 没点出对象时，优先找当前会话上次实际回复中引用过的唯一已核实话题。该话题仍须通过当前来源、有效期、用户暂停与放下等原有检查。
- 没有确定对象、多个对象、来自其他会话、超过七天，或最近那个话题已失效时，不回退到另一个旧话题或一条新发现。临时提醒要求先依据当前对话理解，仍不确定再简短确认，不编后续进展。
- “最近有什么好玩的”保持原来的新鲜度取舍；自主冲浪的候选选择不变。

复用 `data/curiosity/chat-references.json`，在原来的全局分享时间之外增加 `_sessions` 元数据：最多保留 80 个会话的最近一次话题编号及时间，不保存新的聊天原文。它只在现有适配器允许同步的用户回合里记录；未读来信本身不建立关联，原有定时任务与机器人过滤继续保留。多个来源无法确定唯一话题、或后来引用了不属于已核实兴趣的链接时，清除该会话的隐含指向，不接回更早的另一个话题。

原全局时间仍用于减少重复分享，不拿来猜是哪一个会话聊过。旧格式继续可读，不从已有全局时间或未读来信反推会话；升级后新的有效引用才建立关联。没明确对象时少带一条材料，不意味着删除回忆或要求每次重新介绍；Hermes 原有聊天历史和回忆检索继续可用。

## 参考与取舍

查阅了 [dsh-fish-memory 的源码](https://github.com/Yuuyuko-uu/dsh-fish-memory/blob/main/lib/index.js) 中按会话绑定线索的设计，以及 [dsh-feiyu-mood 源码](https://github.com/Yuuyuko-uu/dsh-feiyu-mood/blob/main/lib/index.js) 对用户话语、主动搭话与宿主注入的区分。本轮只参考来源与归属的思路，不复制代码或接入每轮情绪判断。

[Hermes 的后台观察者讨论 #553](https://github.com/NousResearch/hermes-agent/issues/553) 提议独立处理跨会话记忆，同时列出额外调用、过期或矛盾引导等风险；这是提案，不能视为本项目固定版本已有的能力。[主动上下文讨论 #500](https://github.com/NousResearch/hermes-agent/issues/500) 也是设计线索，不证明“活人感”已被验证。当前问题可以在已有兴趣引用里确定地修正，因此没有新增观察者、情绪数值或设置旋钮。

## 验证与限制

全套 Python 370 项通过。新增 12 项兴趣追问检查和 1 项适配器集成检查，覆盖：新兴趣不能抢占旧话题、明确拒绝继续、用户暂停与恢复、点名与带引号的标题、无关联和旧格式、未读来信、不同会话交叉引用、失效话题不回退、多来源与无关链接、时效和损坏数据、读取无写入、记录上限，以及适配器是否传递实际会话编号。

固定 Hermes 的真实 MemoryManager 与候选、已安装适配器分别在虚构临时目录验证：通过真实 `sync_all` 后台同步、等待 `flush_pending` 完成，再经 `prefetch_all` 核对同会话追问、点名换题、普通新发现、其他会话留空。读取不改变虚构兴趣、来源与核心文件。没有向真实聊天注入测试消息，没有付费模型生成；这些检查证明选材链路，不证明最终回复一定自然，也不证明已获得任何新阅读。

这是有限措辞与词语匹配，不能通解所有代词、标题或复杂多对象追问。只提及话题而未引用有效链接时，可能没有可用关联；默认让当前聊天历史承接，不猜测归属。原有引用与权限边界不变，兴趣记录不等于用户偏好。

## 本机更新

`python3 scripts/install_memory.py` 先备份再更新本地适配器，保留身份、核心记忆、模型、审批、三个任务、来信与既有兴趣引用。空闲且无草稿时重载 gateway 插件与内部 API，原生窗口保留；无需重建应用或更新静态人设，不运行 setup_profile.py / setup_jobs.py。新关联在后续真实回合中自然建立，不迁移或伪造旧会话关系。
