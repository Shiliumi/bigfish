界面精简（1.20.0，2026-11-04）

主导航保留聊天、小屋、探索、记忆和来信五项。聊天输入框的表情按钮打开收藏、搜索和来源预览，可放入现有草稿后自行发送。旧版保存的 stickers 页面转到选择器，routines 和 hermes 页面转到设置相应分类；菜单与命令的 Hermes 入口仍能打开高级管理。

设置收拢为模型连接、相处偏好、后台活动和高级。模型地址、密钥、模型列表和连通性测试保留；同一个设置窗口内切换分类时，模型表单保持挂载，保留尚未保存的输入。人格与兴趣编辑统一从相处偏好进入，打开前重新读取当前文档及版本。后台活动集中管理日常安排、执行记录、用量与额度；高级保留运行诊断、工具、技能和全部会话检索，不再重复展示日常卡片和数量统计。

记忆页分为共同回忆、她的成长。共同回忆可在时间线与星图之间切换，事项与约定按需展开并加载；成长页包含人格尝试，核心档案和整理报告展开查看。探索页聚焦冲浪见闻；记忆整理报告移入成长页。核心记忆、更正、遗忘、来源记录与状态数据保留。小屋默认呈现自动或手选的活动状态，四个动作收在互动菜单中，原来的手选保存和自动行为继续有效。

刷新与性能

- 主界面的来信仍按 15 秒检查；概览和最近会话为 60 秒有效期。仅在探索页读取兴趣；文档和表情按入口需要加载，120 秒有效期。手动刷新最近会话只请求会话。
- 同资源在途请求合并；独立资源分别提交结果，单个失败不阻断其他资源。发生修改或对话完成时失效缓存，旧请求的迟到响应不覆盖新状态。打开文档编辑时始终读取新版本。
- 周期刷新在 document.hidden 或原生窗口不可见时跳过，恢复可见时立即检查到期数据。现有聊天连接、按需拍照长轮询和布置草稿保护心跳继续运行，避免关闭主窗口后失去消息或照片处理能力。
- 小鲸鱼弹层可见时的状态检查从 3 秒改为 5 秒，并检查原生窗口可见性。概览接口移除没有界面消费者的已读网页数组和核心记忆数量，省去对应文件读取。
- 记忆说明默认折叠，高级设置集中显示；任务时间、执行错误、来源、预算边界仍可查看。

新增刷新测试覆盖并发去重、修改与旧响应竞争、单资源失败重试、按需失效。在固定 150 秒模拟中，普通聊天主界面的这组六个资源请求由旧逻辑的 66 次变成 17 次；只描述这组前端请求，不包含原生通知、连接心跳和拍照等请求，不代表整机耗电、CPU 或 token 同比例下降。本轮没有修改模型提示、人格、记忆召回或任务日程，也没有新增模型调用；未测得实际账单节省。

验收：TypeScript 与生产构建通过，122 项 Node 检查通过。隔离虚构档案中验证表情加入已有草稿、切换设置保留模型输入、任务暂停与执行记录、成长页，以及 520×420 窗口的设置分类和内容滚动。真实任务开关与档案未用于修改验收。Mac 应用更新为 1.20.0（build 27），已核对五项主导航、小屋互动菜单、草稿保护与原生 ⌘2 高级管理入口；三个旧页面入口在隔离界面中完成迁移检查。
